# 🧱 Флексбокс

- [[display flex]] (включение флекс-контейнера)
- [[flex-direction]] (направление главных осей)
- [[justify-content]] (выравнивание по главной оси)
- [[align-items]] (выравнивание по поперечной оси)
- [[flex-wrap]] (перенос элементов)
- [[gap]] (расстояние между элементами)
- [[flex-grow]] (коэффициент растяжения)
- [[flex-shrink]] (коэффициент сжатия)
- [[flex-basis]] (базовый размер элемента)
- [[align-self]] (выравнивание отдельного элемента)
- [[order]] (порядок вывода элемента)
